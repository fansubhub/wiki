## ¿Para qué sirve?

Esta librería expande enormemente las capacidades de las tablas estándar de Lua. No solo ofrece herramientas para manipular y consultar tablas, sino que también incluye funciones avanzadas para procesar datos, generar secuencias y realizar operaciones complejas que son fundamentales para la creación de efectos dinámicos.

## Funciones

### Funciones de inspección e información

<Tabs>
<TabItem label="table.view(Table, Name, indent)">
Muestra el contenido completo de una tabla en un formato de texto legible. Invaluable para depurar.


<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla a visualizar.
    - `Name:? string`, _opcional_: Nombre para la tabla en la salida de texto.
</Aside>
</TabItem>

<TabItem label="table.inside(Table, e, str1, str2)">
Comprueba si un elemento, tipo de elemento (`number`, `string`) o patrón de texto existe dentro de una tabla. Devuelve `true` o `false`.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla donde se buscará.
    - `e: any`: El elemento a buscar.
</Aside>
</TabItem>

<TabItem label="table.index(Table, e, str1, str2)">
Devuelve el **índice** (la posición) del primer elemento que coincida con la búsqueda.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla donde se buscará.
    - `e: any`: El elemento cuyo índice se quiere encontrar.
</Aside>
</TabItem>

<TabItem label="table.compare(Table1, Table2)">
Compara dos tablas de forma profunda para ver si son idénticas en contenido y estructura.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table1: table` `Table1: table`: La tablas a comparar.
</Aside>
</TabItem>

<TabItem label="table.type(Table)">
Analiza el contenido de una tabla y determina un **tipo** general para sus elementos, como `number`, `string`, `shape`, `color`, etc.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla a analizar.
</Aside>
</TabItem>

<TabItem label="table.count(Table, e)">
Comprueba si un elemento, tipo de elemento (`number`, `string`) o patrón de texto existe dentro de una tabla. Devuelve `true` o `false`.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla donde contar.
    - `e: any`: El elemento, tipo o patrón a contar.
</Aside>

#### Ejemplo

```lua
local cantidad_numeros = table.count({1, "a", 2}, "number") -- Devuelve: 2
```
</TabItem>

<TabItem label="table.pos(Table, e)">
Devuelve una tabla con todos los **índices** en los que se encuentra un elemento, tipo o patrón.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla donde buscar.
    - `e: any`: El elemento, tipo o patrón a localizar.
</Aside>

#### Ejemplo

```lua
local posiciones = table.pos({"a", "b", "a"}, "a") -- Devuelve: {1, 3}
```
</TabItem>
</Tabs>

### Funciones de manipulación y modificación

<Tabs>
<TabItem label="table.duplicate(Table)">
Crea una copia exacta y profunda de una tabla. Crucial para modificar una tabla sin alterar la original.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla a duplicar.
</Aside>
</TabItem>

<TabItem label="table.disorder(Table)">
Desordena aleatoriamente los elementos de una tabla.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table | number`: La tabla a desordenar. Si es un número, crea una tabla del `1` a **ese número** y la desordena.
</Aside>
</TabItem>

<TabItem label="table.retire(Table, ...)">
Elimina elementos de una tabla por su **índice** o por un **rango de índices**.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla.
    - `...: number | table`: Índices individuales (`2, 4`) o un rango (`{{2, 5}}`).
</Aside>
</TabItem>

<TabItem label="table.reverse(Table)">
Invierte el orden de los elementos de una tabla.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla.
</Aside>
</TabItem>

<TabItem label="table.cyclic(Table)">
Crea una tabla cíclica (palíndromo sin el último elemento). `{a, b, c, d}` se convierte en `{a, b, c, d, c, b}`.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table | number`: La tabla.
</Aside>
</TabItem>

<TabItem label="table.inserttable(Table1, Table2, Index)">
Inserta todos los elementos de `Table2` dentro de `Table1` en una posición específica.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table1: table` `Table2: table`: La tablas.
    - `Index?: number`, _opcional_: Posición de inserción. Por defecto, al final.
</Aside>
</TabItem>

<TabItem label="table.gsub(Table, Capture, Replace)">
Aplica `string.gsub` a todos los elementos de tipo `string` dentro de una tabla.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla a modificar.
    - `Capture: string`: El patrón a buscar.
    - `Replace: string`: El texto de reemplazo.
</Aside>
</TabItem>

<TabItem label="table.unique(Table)">
Elimina los elementos duplicados de una tabla, dejando solo una aparición de cada uno.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla.
</Aside>

#### Ejemplo

```lua
table.unique({1, 2, 2, 3}) -- Devuelve: {1, 2, 3}
```
</TabItem>

<TabItem label="table.unique(Table)">
Convierte una tabla con claves no numéricas (asociativa) en una tabla indexada (un array), descartando las claves.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla.
</Aside>

#### Ejemplo

```lua
table.ipairs({a="rojo", b="verde"}) -- Devuelve: {"rojo", "verde"}
```
</TabItem>

<TabItem label="table.inpack(Table, Group)">
Agrupa los elementos de una tabla en sub-tablas de un tamaño determinado.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla.
    - `Group: number`: El número de elementos que tendrá cada sub-tabla.
</Aside>

#### Ejemplo

```lua
table.inpack({1,2,3,4,5,6}, 2) -- Devuelve: {{1,2}, {3,4}, {5,6}}
```
</TabItem>

<TabItem label="table.filter(Table, Filter)">
Filtra una tabla, devolviendo solo los elementos que cumplen una condición definida por una función de filtro. Es la contraparte de `table.match`, pero en lugar de buscar un valor, evalúa una condición lógica.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla cuyos elementos se van a filtrar.
    - `Filter: function`: Una función que recibe dos argumentos, `k` (la clave o índice) y `v` (el valor del elemento). La función debe devolver `true` para los elementos que se desean conservar en la nueva tabla.
</Aside>

#### Ejemplo

```lua
-- Define un filtro que solo acepta números impares.
local filtro_impares = function(k, v)
    if v % 2 == 1 then
        return true
    end
    return false
end

-- Aplica el filtro a una tabla.
local mi_tabla = {1, 2, 3, 4, 5, 6}
local tabla_filtrada = table.filter(mi_tabla, filtro_impares) -- Devuelve {1, 3, 5}
```
</TabItem>
</Tabs>

### Funciones de combinación y creación

<Tabs>
<TabItem label="Varias">
:::note[table.concat1—table.concat4 / table.twin]
:::

Funciones avanzadas para combinar tablas de diferentes maneras, creando permutaciones y emparejamientos. Se recomienda experimentar para entender su salida.
</TabItem>

<TabItem label="table.combine(Table, n)">
Genera todas las combinaciones posibles de `n` elementos a partir de una tabla.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla.
    - `n: number`: El tamaño de cada combinación.
</Aside>

#### Ejemplo

```lua
table.inpack({1,2,3,4,5,6}, 2) -- Devuelve: {{1,2}, {3,4}, {5,6}}
```
</TabItem>

<TabItem label="table.permute(Table)">
Genera todas las permutaciones (órdenes) posibles de los elementos de una tabla.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla.
</Aside>
</TabItem>

<TabItem label="table.create(Size, Config)">
Crea una tabla de un tamaño específico, llenando cada posición con un valor o una copia de una tabla.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla.
    - `Config: any`: El valor con el que se llenará cada posición.
</Aside>
</TabItem>

<TabItem label="table.replay(Len, ...)">
Repite un conjunto de elementos un número determinado de veces para crear una tabla más grande.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Len: number`: El número de veces que se repetirá la secuencia.
    - `...: any`: Los elementos a repetir.
</Aside>

#### Ejemplo

```lua
table.replay(3, "a", "b") -- Devuelve: {"a", "b", "a", "b", "a", "b"}
```
</TabItem>

<TabItem label="table.string(String, n)">
Divide una cadena de texto en una tabla de sub-cadenas, cada una con una longitud de `n` caracteres.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `String: string`: La cadena de texto a dividir.
    - `n: number`: El tamaño de cada parte.
</Aside>

#### Ejemplo

```lua
table.string("abcdef", 2) -- Devuelve {"ab", "bc", "cd", "de", "ef"}
```
</TabItem>

<TabItem label="table.capture(String, Capture)">
Realiza una búsqueda global (`gmatch`) sobre un texto y devuelve todas las capturas en una tabla.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `String: string`: El texto donde buscar.
    - `Capture: string`: El patrón de búsqueda.
</Aside>

#### Ejemplo

```lua
table.capture("hola 123 mundo", "%d+") -- Devuelve: {"123"}
```
</TabItem>

<TabItem label="table.match(Table, Capture)">
Devuelve una nueva tabla que contiene solo los elementos de la tabla original que coinciden con el valor, tipo o patrón de búsqueda.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla a filtrar.
    - `Capture: any`: El criterio de coincidencia.
</Aside>
</TabItem>
</Tabs>

### Funciones de procesamiento avanzado

<Tabs>
<TabItem label="table.op(Table, Mode, add)">
Una función "multiherramienta" que realiza diversas operaciones matemáticas o de ordenamiento sobre una tabla.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla.
    - `Mode: enum`: La operación a realizar: `"sum"`, `"average"`, `"min"`, `"max"`, `"org"` (ordenar), `"concat"`, etc.
    - `add: varía`, _opcional_: Un valor adicional para ciertas operaciones.
</Aside>
</TabItem>

<TabItem label="table.ipol(Table, Size, Tags, algorithm)">
Interpola valores entre los elementos de una tabla. Puede interpolar números, colores, alfas, _shapes_ y _clips_. Es fundamental para animaciones suaves.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla.
    - `Size: number`: El número de pasos de interpolación.
    - `Tags: string | table`, _opcional_: Una etiqueta de ASS (p.e. `\fscx`) para añadir a cada valor.
    - `algorithm: string`, _opcional_: Una fórmula para la aceleración (ej. `"sin(pi/2 * %s)"`).
</Aside>
</TabItem>

<TabItem label="table.filter(Table, Filter)">
Filtra una tabla, devolviendo solo los elementos que cumplen una condición definida por una función.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla a filtrar.
    - `Filter: function`: Función que recibe `(índice, valor)` y devuelve `true` para conservar el elemento.
</Aside>
</TabItem>
</Tabs>

### Funciones misceláneas

<Tabs>
<TabItem label="table.random(Table)">
Una función "multiherramienta" que realiza diversas operaciones matemáticas o de ordenamiento sobre una tabla.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `Table: table`: La tabla de la que se elegirá un elemento.
</Aside>
</TabItem>

<TabItem label="table.remember(table_ref, table_val)">
Versión de `remember` para tablas. Guarda múltiples pares de referencia-valor en la tabla `recall` de una sola vez.

<Aside type="tip" title="Argumentos" icon="list-format">
    - `table_ref: table`: Tabla con los nombres (_strings_) de las referencias.
    - `table_val: table`: Tabla con los valores a guardar.
</Aside>
</TabItem>
</Tabs>
