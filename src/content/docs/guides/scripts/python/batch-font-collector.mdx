## Características

- Procesa múltiples archivos de subtítulos .ass por lotes.
- Recopila todas las fuentes necesarias para cada archivo de subtítulos.
- Organiza las fuentes en carpetas por episodio.
- Registra el proceso de extracción (process.log).
- Informa de las fuentes que faltan (missing_fonts.log).

## Uso

<Steps>
1. Abra un terminal.

2. Navegue hasta la carpeta que contiene el _script_ `batch_font_collector.py`.

3. Ejecute el _script_ con la ruta a su carpeta de subtítulos:
    ```bash
    python batch_font_collector.py "/ruta/a/los/subtítulos"
    ```
</Steps>
