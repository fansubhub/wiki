**Advanced SubStation Alpha (`.ass`)** es el estándar por defecto en la comunidad de *fansubbing* para la creación de subtítulos complejos. A diferencia de formatos básicos como `.srt`, permite un control tipográfico total, maquetación (*typesetting*), efectos visuales y posicionamiento exacto sobre el lienzo del vídeo.

:::note[Evolución del formato]
Es la evolución directa de **SubStation Alpha v4 (`.ssa`)**, introduciendo soporte completo para estilos avanzados, [transformaciones](/aegisub/tags/advanced/transform) [vectoriales](/aegisub/tags/advanced/clip), [transparencias alfa](/aegisub/tags/basic/color) y mayor precisión en el renderizado con motores como `libass`.
:::

## Capacidades principales

<Card title="Estilos y tipografía" icon="pencil">
* Definición global de fuentes, tamaños, colores primarios, secundarios y sombras.
* Control preciso de [bordes](/aegisub/tags/basic/border) (*outline*), degradados y opacidad por canal alfa.
* Soporte para fuentes personalizadas incrustadas directamente en contenedores MKV.
</Card>

<Card title="Posicionamiento y transformación" icon="laptop">
* Coordenadas exactas en pantalla mediante [etiquetas de posición](/aegisub/tags/basic/position) (`\pos`).
* [Rotación](/aegisub/tags/advanced/rotation) y [escalado tridimensional](/aegisub/tags/advanced/sizing) (`\frz`, `\frx`, `\fry`, `\fscx`, `\fscy`).
* [Alineación](/aegisub/tags/basic/alignment) flexible según el teclado numérico estándar (`\an1` a `\an9`).
</Card>

<Card title="Efectos y karaoke" icon="rocket">
* [Animaciones temporales](/aegisub/tags/advanced/transform) suaves mediante interpolación (`\t`).
* Sincronización silábica avanzada para karaoke (`\k`, `\kf`, `\ko`).
* [Trazado de gráficos y máscaras vectoriales](/aegisub/tags/basic/scale) con comandos de dibujo (`\p1`).
</Card>

<Card title="Estructura en texto plano" icon="document">
* Formato legible estructurado por bloques (`[Script Info]`, `[V4+ Styles]`, `[Events]`).
* Fácil control de versiones y compatibilidad universal con editores de texto.
</Card>
