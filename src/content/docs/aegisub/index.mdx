**Aegisub** es una herramienta gratuita, multiplataforma y de código abierto para crear y modificar subtítulos. Permite sincronizar los subtítulos con el audio de forma rápida y sencilla, y cuenta con muchas herramientas potentes para darles estilo, incluida una vista previa de vídeo en tiempo real incorporada.

Las versiones estables y documentación puede encontrarse en [su sitio oficial](https://aegisub.org/). Las versiones más avanzadas con herramientas recomendadas para [_typesetting_](/p/typesetting) que la versión oficial no incluye, puedes encontrarla en el repositorio de GitHub de [arch1t3cht](https://github.com/arch1t3cht/Aegisub).

## Historia

Aegisub originalmente se creó como una herramienta para hacer del proceso de formateo, particularmente en [_fansubs_](/fansub) de anime, una experiencia menos dolorosa. Al inicio del proyecto, a muchos otros programas que manejaban el formato [**Advanced Substation Alpha**](/files/ass) (ASS) les faltaban (y en muchos casos les siguen faltando; desarrollo en varios programas competidores desde entonces se ha abandonado por razones completamente ajenas a Aegisub) varias funciones esenciales, o tenían demasiados errores o poca fiabilidad como para ser realmente útiles.

Desde entonces, Aegisub ha crecido hasta ser un editor de subtítulos completo y altamente personalizable. Goza de muchas herramientas convenientes para ayudar al [**sincronizar**](/p/timing), [**formatear**](/p/typesetting), editar y [**traducir**](/p/translate) subtítulos, además de un potente ambiente de programación llamado [**Automation**](/aegisub/automation) (originalmente en gran medida motivado hacia crear [efectos **karaoke**](/p/karaoke), Automation ahora puede usarse para mucho más, incluyendo definición de macros y varias otras funciones útiles).
