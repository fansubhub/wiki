| Sintaxis | Estado | Descripción |
| :--- | :--- | :--- |
| `{\b1}` | **Activado** | Aplica formato de negrita al texto siguiente. |
| `{\b0}` | **Desactivado** | Quita la negrita del texto siguiente. |
| `{\b}` | *Por defecto* | Restablece el valor predeterminado del estilo. |
| `{\b<peso>}` | *Personalizado* | Ajusta el peso explícito (ej. `{\b700}` para *bold*, `{\b400}` para regular). |

## Ejemplo

```text
Estoy de muy {\b1}mal{\b0} humor.
```
