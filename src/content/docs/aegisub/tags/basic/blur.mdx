## Simétrico

Actúa sobre el cuerpo principal del objeto o texto y su sombra [en caso de que la tenga]. Si el objeto tiene borde, entonces actúa sobre el borde y no sobre el cuerpo principal. En cualquiera de los dos casos `\blur` **siempre** actuará sobre la sombra del elemento.

| Sintaxis | Estado | Descripción |
| :--- | :--- | :--- |
| `{\blur0}` | **Desactivado** | Quita el desenfoque del texto siguiente. |
| `{\blur}` | *Por defecto* | Restablece el valor predeterminado del estilo. |
| `{\blur<0-100>}` | *Personalizado* | Ajusta el desenfoque del texto u objeto dentro del rango permitido, decimales incluidos. |

### Ejemplo

```text
{\blur2}Ejemplo.
```

## Asimétrico

El desenfoque asimétrico es similar al simétrico, pero con una aceleración de la dispersión diferente; útil a la hora de crear desenfoques por profundidad de campo. Tiene los mismos efectos sobre el cuerpo principal, sombra y borde que el desenfoque simétrico.

| Sintaxis | Estado | Descripción |
| :--- | :--- | :--- |
| `{\be0}` | **Desactivado** | Quita el desenfoque del texto siguiente. |
| `{\be}` | *Por defecto* | Restablece el valor predeterminado del estilo. |
| `{\be<0-100>}` | *Personalizado* | Ajusta el desenfoque del texto u objeto dentro del rango permitido, decimales incluidos. |

### Ejemplo

```text
{\be2}Ejemplo.
```
