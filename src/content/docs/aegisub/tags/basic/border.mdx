Esta etiqueta puedes controlarla tanto uniformemente `\bord` como por cada uno de sus ejes: `\xbord` y `\ybord`. Cada una de estas variables controla el nivel de borde del texto u objeto en el eje correspondiente.

| Sintaxis | Estado | Descripción |
| :--- | :--- | :--- |
| `{\bord0}` | **Desactivado** | Quita el borde del texto siguiente. |
| `{\bord}` | *Por defecto* | Restablece el valor predeterminado del estilo. |
| `{\bord<borde>}` `{\xbord<borde>}` `{\ybord<borde>}` | *Personalizado* | Ajusta el borde del texto con un valor positivo (de `0` a `∞`), pudiendo contener decimales. |

:::caution[Sobrescritura]
Si utilizas `\bord` después de `\xbord` o `\ybord` [en el mismo bloque], este sobrescribirá los valores anteriores de esas etiquetas.
:::

## Ejemplo

```text
{\bord2}Ejemplo.
```
