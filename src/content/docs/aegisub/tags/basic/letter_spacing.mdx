La función de esta etiqueta es cambiar el espacio (píxeles) entre los caracteres del texto al que afetca. Si se usan valores positivos, la separación será mayor. En caso de usar valores negativos, la separación será negativa y los caracteres se apilarán.

| Sintaxis | Estado | Descripción |
| :--- | :--- | :--- |
| `{\fsp<espacio>}` | *Personalizado* | Ajusta el espaciado con un valor positivo (de `0` a `∞`) o negativo, pudiendo contener decimales. |
| `{\fsp}` | *Por defecto* | Restablece el valor predeterminado del estilo. |

## Ejemplo

```text
{\fsp100}Ejemplo
```
