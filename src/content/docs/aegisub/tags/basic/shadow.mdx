Esta etiqueta puedes controlarla tanto uniformemente `\shad` como por cada uno de sus ejes: `\xshad` y `\yshad`. Cada una de estas variables controla el nivel de sombra del texto u objeto en el eje correspondiente.

| Sintaxis | Estado | Descripción |
| :--- | :--- | :--- |
| `{\shad0}` | **Desactivado** | Quita el borde del texto siguiente. |
| `{\shad}` | *Por defecto* | Restablece el valor predeterminado del estilo. |
| `{\shad<sombra>}` `{\xshad<sombra>}` `{\yshad<sombra>}` | *Personalizado* | Ajusta la sombra del texto u objeto con un valor positivo (de `0` a `∞`), pudiendo contener decimales. |

:::caution[Sobrescritura]
Si utilizas `\shad` después de `\xshad` o `\yshad` [en el mismo bloque], este sobrescribirá los valores anteriores de esas etiquetas.
:::

## Ejemplo

```text
{\shad2}Ejemplo.
```
