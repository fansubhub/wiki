La etiqueta declara la escala del dibujado vectorial, utilizado mayoritariamente en formas (_shapes_).

| Sintaxis | Estado | Descripción |
| :--- | :--- | :--- |
| `{\p0-∞}` | *Personalizado* | Ajusta la escala del dibujo tras las llaves `{}`. |

## Ejemplo

```text
{\p1}m 796 428 l 992 428 992 632 796 632
```
