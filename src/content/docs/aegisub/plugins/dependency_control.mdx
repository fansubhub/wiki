---

import { Steps } from '@astrojs/starlight/components';

<Steps>

1. Para utilizar cualquier automatización debes ir al menú **Automatización**.

    ![automatizacion.png](https://media.fansubhub.com/d/uploads/images/aegisub/automatization/automatizacion.png?sign=qG1rGSR4P2LQT6GtZOvN1R__Z2EA1U3LHUGSSMYnzkM=:0)

2. Una vez allí, selecciona **Dependency Control** y haz clic sobre **Install Script**.

    ![dependency.png](https://media.fansubhub.com/d/uploads/images/aegisub/automatization/dependency-1.png?sign=7Z7OzYng80tHYKth-lrLNuCurEWDqiBIAiMtMh1nVqM=:0)

3. Selecciona la automatización a instalar y haz clic en OK.

    ![dependecy.png](https://media.fansubhub.com/d/uploads/images/aegisub/automatization/dependency-2.png?sign=upit89d70qXT7hCvl9hhINyWHHdKTVq5oyYx2QRJ8-8=:0)

4. Una vez termine la instalación, ve al administrador de automatizaciones y haz clic en **Revisar directorio de carga automática**.

    ![revisar.png](https://media.fansubhub.com/d/uploads/images/aegisub/automatization/revisar.png?sign=odfggWiNKQ7c8HmlHcSeCIeJ7oUTzEcom9PtD1na9xo=:0)

</Steps>

Terminado este proceso, tu nuevo _plugin_ debería estar listo para usarse.
